# 負側の仕事と次の頂点を比べる一括実験（1.0.15）

## 操作

脚の前後移動を前回と同じ方法で固定する。保存済みの直立基準を使用し、測定前のホイールを落ち着かせる。実機画面の「負側5条件の一括実験を開始」を押すだけで、目標8°・指令300 mA・正側の従来制御・学習補正なし・30秒測定を設定する。通常制御の入力欄はこの実験に影響しない。

1. 一括実験を開始し、30秒の終了を待つ。想定外の振幅や挙動は緊急停止する。
2. 電源を切る前にRWLOGを取得する。ファイルを確認してから「ログを消去・次の測定へ」を押す。
3. 同じ固定方法でまず5回繰り返す。各回を別ファイルとして保存する。

## 割当と記録

負側の受理されたZEROクロスを5回ずつのブロックに区切る。各ブロックには0・10・15・20・25 msを各1回入れ、測定回ごとのシードから順序を変える。ブロック境界では同じ時間が連続する場合もある。角速度が既存モデルの対象範囲外なら指令を実行せず、予定条件と未実行理由を残す。未実行でもその割当を消費し、条件の選び直しはしない。

RWLOGメタデータの `negative_probe_batch_seed` と `negative_probe_batch_algorithm` で割当順序を再現できる。`negative_probe_batch_schedule_ms` は最初の40割当の見本で、実際の各ZEROクロスには `negative_probe_batch_index`、`negative_probe_batch_planned_width_ms`、`negative_probe_batch_rate_skipped`、`pulse_width_ms`、`output_executed` を記録する。これまでどおり生のIMU、時刻付きホイール位置・回転速度・電流・電圧、実際の指令適用時刻を保存する。RWLOG v56の試料形式は変えない。

## 取得後の解析

入力前の機体角速度・位置由来のホイール回転数を用い、開始10秒以降で状態の近い記録を比較する。前回の3回では、機体角速度の絶対値70～76°/s、ホイール回転数20～120 rpmの条件に1回あたり約15件入った。今回も同じ範囲を候補とするが、採用件数と条件間の重なりを確認してから比較する。計測中に本体がこの範囲への到達を待つ処理はない。

仕事は通電中と停止後から次の負側ピークまでを分けて計算する。0 msの例を基準に、入力による仕事の差と次の頂点の位置エネルギーの差を比較する。5回のうち1回を外して関係を求め、外した回を予測する。ホイール慣性 `2.8×10^-5 kg m²` と軸符号は暫定値で、係数1のエネルギー収支が実証されたことを前提にしない。
