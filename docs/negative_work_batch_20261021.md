# 負側入力の一括測定

実機動作用ファームウェアの「負側5条件の一括測定を開始」を押すと、目標角8°・指令300 mA・正側の既存の旧式換算制御・学習補正なしで30秒測定する。脚と胴体の固定条件を前回と同じにする。始動キック、開始と終了のLED同期は従来どおり。

負側の受理されたZEROクロスごとに、RAW +300 mAの入力時間を以下の20条件の順で設定し、必要なら先頭から繰り返す。

| 1～5 | 6～10 | 11～15 | 16～20 |
| --- | --- | --- | --- |
| 0, 10, 15, 20, 25 | 20, 15, 10, 25, 0 | 25, 20, 0, 10, 15 | 10, 0, 25, 15, 20 |

各時間は20条件中に4回ずつ現れる。0 msではモータを入力しない。ZEROクロス時の角速度が既存モデルの対象外なら、その条件を無理に出力せず、予定時間と未実行を記録する。実際に得られる各条件の回数は運動状態によって変わる。大きく崩れる場合は緊急停止を使う。

RWLOG v56の172 byte/行は維持する。生の加速度・角速度、時刻付きホイール位置・速度・電流・電圧、モータ指令・適用時刻を記録する。各ZEROクロスのメタデータには `negative_probe_batch_index`、`negative_probe_batch_planned_width_ms`、`negative_probe_batch_rate_skipped`、実際の `pulse_width_ms` と `output_executed` を保存する。マイコン内で仕事や損失の同定は行わない。足カメラは従来どおりマーカーの検出結果を記録するが、画像そのものはRWLOGに含まれない。

測定後はRWLOGをダウンロードし、ファイルを確認してからログを消去する。開始姿勢・固定方法・ホイール回転状態をできるだけそろえて一括測定をまず3回行う。同じ一括測定内の条件は独立ではないため、PC側で入力直前の角速度、ホイール回転数、電池電圧を合わせて比較する。仕事は入力中と入力終了から次の負側ピークまでを分けて計算する。記録領域はPSRAM上なので、再起動前に必ずダウンロードする。
