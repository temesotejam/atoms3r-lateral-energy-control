# 固定脚・負側ブレーキ比較（2026年10月14日）

目的は、負側のブレーキが負側ピークと**次の正側ZEROクロス速度・ピーク角**に与える影響を分けて見ること。歩行性能の検証ではない。

## 測定条件

- 足を前後に動かないよう固定し、左右の揺動だけを測る。固定方法、重心位置、モータ取付方向は全試行で同じにする。
- 同一のファームウェアを使い、目標8°、指令電流300 mA、始動キック、正側の制御は固定する。
- 負側ブレーキ上限だけを0・20・50 msから選ぶ。50 msが従来条件。各条件を最低3回測り、可能なら実施順を入れ替える。
- 各試行の開始前に機体を静止させ、ホイール回転数と電池電圧を確認する。試行中も16°停止条件を維持する。
- 測定が終わるたびにRWLOGを保存し、条件名が分かるように保管する。画面上の選択値に加え、ログの `energy_control_autonomous_negative_side_brake_width_max_ms` を確認する。

## 比較する値

始動直後を除く共通区間（まずは測定開始5秒以降）で、各負側ZEROクロスから負側ピーク、その次の正側ZEROクロス・正側ピークまでを対応付ける。負側ピーク角、次の正側ZEROクロス角速度、正側ピーク角、正側入力の上限到達回数、実測電流積分、ホイール回転数、電池電圧を並べる。平均だけでなく各周期の値とばらつきを残す。

負側ブレーキと正側ピークの関係は、開始時の機体速度とホイール回転数に左右される。条件ごとの単純平均だけで因果関係を決めない。0 msでも負側が安全な角度を保ち、正側が改善するなら、次に必要最小限のブレーキ則を検討する。正側が改善しなければ、ZEROクロス前からの入力時期比較と、ホイール回転状態を含むモデル検証へ進む。
