# 1.0.35：仕事制御の8°・10°・12°プリセット

本体Web画面に目標±8°・±10°・±12°の専用開始ボタンを追加する。各30秒、絶対角0°基準、開始時の姿勢差し引きなし。直立基準の保存は不要。手動の電流・時間指定を必要としない。まず10°を試し、その記録を確認してから12°へ進む。

## 制御の変更

- 左右別の目標エネルギーを `U(+target,x)` と `U(-target,x)` から計算する。電流時間積分をエネルギーと同一視しない。
- 本体の開始検証とHTTPの入力検証の両方で、仕事制御の8°・10°・12°を許可する。旧15秒の逆算実験と固定入力同定パッケージは8°のまま。
- 自動補正は各測定でゼロから始め、既存の左右別エネルギー残差と等価重心の適応を維持する。過去3件の残差の使い方、±0.5 mJの補正上限、6〜13°の観測角条件は維持する。
- 負側入力の保護を目標に追従させる。正側がtarget−1°未満なら負側入力を見送り、target−1°〜target−0.2°の位置エネルギーで許容上限をなだらかに変える。40 msを超える学習上限の拡張には正側target−0.2°以上を必要とする。
- 本体画面の左右の目標エネルギーも、選択中の目標角に対応する値を表示する。

## 試験用の適用範囲

回帰式の係数は8°時のモデルを保持する。10°・12°の式を新しいデータで再同定したという意味ではない。角速度による運動エネルギーと入力中・入力後の仕事をそのまま評価し、入力候補を目標エネルギーに照合する。

従来方式の10°・12°記録では8°より高い角速度が観測されている。このため、通常仕事制御の角速度の全重み区間上端を以下の試験用上限とする。値は適用範囲の上限であり、角速度の制御目標ではない。10°・12°で全状態の入力効果が検証済みとは扱わない。

| 目標 | 正側上端 | 負側上端 |
| --- | ---: | ---: |
| 8° | 72.7405°/s | 76.2778°/s |
| 10° | 85°/s | 90°/s |
| 12° | 95°/s | 100°/s |

上端の外では従来の余裕幅（正側4°/s、負側2°/s）で重みを減らす。下端、電圧範囲、回転速度範囲、センサ鮮度の制限は維持する。負側モデルの直前ピーク上端はtarget＋2°とし、その外0.3°で重みを減らす。10°・12°の予測はcross-conditionとして記録する。旧厳密適用範囲の関数は変更しない。

正側電流候補300/350/400 mA、最大100 ms・25 mA s、負側300 mA・初期上限25 ms・段階的な最大70 msは変更しない。上限で目標に届かない場合は飽和を記録し、自動で電流や時間の上限を増やさない。

## 記録・検証

RWLOGに目標角、10°・12°の試験条件フラグ、目標に対応する角速度上限を追加する。既存の予測エネルギー、実測ピーク、入力量、未適用のエネルギー差、飽和フラグで次の測定を評価する。

検証は、専用ボタンからの8/10/12°開始要求、旧実験の設定制限、目標位置エネルギーと逆算、目標に追従する入力抑制、上限での範囲外棄却、入力上限と試験条件フラグを対象とする。8°の回帰検証も維持する。10°・12°の閉ループ精度は実機測定で確認する。
