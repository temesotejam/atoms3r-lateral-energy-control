# 正側300・350・400 mAの一括測定

前回の固定脚実験では、負側の300 mA入力を30 msから40 msへ延ばすと、負側のピークは平均9.51°から9.12°へ下がった一方、次の正側ピークも7.69°から7.42°へ下がりました。この測定では負側を300 mA・40 msに固定し、正側の電流だけを変えます。正側の不足を補いながら負側の過大な揺れを減らせるかを調べます。これは制御則の係数を求める測定であり、通常の15秒制御を変更しません。

## 準備・測定

1. 脚の前後移動を、前回の固定脚測定と同じ方法で固定します。左右の揺れは自由にします。
2. 本体に `1.0.22-positive-current-start-fix` を書き込みます。直立姿勢で静止させ、必要なら「今の姿勢を直立基準として保存」を押します。
3. 実機Web画面の「正側の電流3条件を測定」を押します。目標8°、始動キック300 mA、負側300 mA・40 ms、正側300・350・400 mA、測定30秒が自動で設定されます。正側の入力時間は従来の予測式で決めます。
4. 終了後、RWLOGを保存してから「ログを消去・次の測定へ」を押します。同じ条件で5回を目安に繰り返します。途中で固定方法を変えた場合は、その前後を別群として扱います。

正側の3条件は、正側ZEROクロス3回を1組として各条件を1回ずつ割り当て、組内の順序を変えます。最初の始動キックはこの割当に含みません。負側では、直前の正側ピークが7°未満、電池電圧が7.0～8.5 Vの範囲外、またはZEROクロス速度が既存モデルの適用範囲外なら入力を見送ります。この場合、負側40 msの結果として扱わないでください。

## 解析

RWLOGの `positive_current_batch_index` と `positive_current_batch_planned_mA` が正側の割当条件です。実際の入力は同じZEROクロス記録の `output_executed`、`command_current_mA`、`pulse_width_ms`、時系列のモータ指令で確認します。割当値のみで未実行を測定結果に含めないでください。正側ZEROクロスから正側ピーク、次の負側ピークまで対応付けます。各条件の到達角、正側入力時間の上限到達率、入力中と停止後のホイールの仕事、電池電圧、入力前ホイール回転速度を比較します。

350・400 mAでの位置エネルギー予測は、300 mAで得た到達角モデルを電流応答で延長する暫定値です。実測ピークと予測値の差を必ず確認します。ホイールの仕事の絶対値も暫定慣性モーメントに依存します。
