# 一つ先の負側ピーク予測：新しいログでの確認手順

## 何を確認するか

固定脚の5回分の記録から作った式を、係数を変えずに新しい測定へ適用する。ZEROクロス時点の角速度、入力前ホイール回転数、直前ピーク、電池電圧、割り当てた入力時間から次の負側ピークを予測し、後で実測ピークと比較する。実測ピークや入力後の回転数・仕事を予測計算には入れない。式の予測はブラウザでRWLOGを開いた後に行い、実機の制御には接続しない。

予測する位置エネルギーは `E_free(入力前状態, 電圧) + η × {W_on(入力時間) + W_off(入力時間) − W_off(0 ms)}` とする。`W_on` と `W_off` は入力前の情報だけで予測したホイールの仕事であり、`η=0.441993856...` は残差をまとめる暫定係数。角度への変換はこの計算の最後に行う。式の係数は元の5回・108イベントに固定し、この確認では更新しない。

## 実機での測定

実機に1.0.16以降の一括実験プログラムが入っていれば、この確認のための再書き込みは不要。

1. 前後の脚移動を従来と同じ方法で固定し、ホイール・錘・重心位置・固定方法を変えない。直立基準を確認する。測定回ごとに原点を取り直さない。
2. 機体のWeb画面で「負側5条件の一括実験を開始」を押す。目標8°、300 mA、30秒、負側0・10・15・20・25 msの順序変更が自動で設定される。正側は既存制御のまま。
3. 終了後、電源を切る前にRWLOGを取得する。各回のRWLOGを保存してから「ログを消去・次の測定へ」を押す。
4. 充電直後に2回測る。通常の使用で電圧が下がった状態でも2回測る。その後、充電し直して1回測る。各回を独立した記録として保存し、順番は **高・高・低・低・高** とする。低電圧にするためだけの放電運転は行わず、通常使用でその状態になったときに続ける。どの回でも画面に表示される電池電圧を記録する。

電圧の呼び名だけで群分けせず、解析では各ZEROクロスに保存された `vbat_mV` を用いる。電圧が元の学習範囲6.21～7.25 Vを外れた予測もCSVに出すが、範囲外と明記して別集計にする。高・低・高の順で、電圧と測定時間・機構の温まりが一緒に変化する問題を少し分けて調べる。

## RWLOGを保存した後

1. [解析ページ](https://temesotejam.github.io/atoms3r-lateral-energy-control/wheel-work.html)でRWLOGを選び、「計算する」を押す。
2. 「予測と実測のCSVを保存」を押す。ファイル名末尾は `_one_peak_prediction.csv`。各条件の割当時間、実行時間、入力前状態、電池電圧、予測した通電中・停止後の仕事と次ピーク、実測次ピーク、誤差、学習範囲内かどうかを記録する。
3. RWLOG本体とCSVを1組として保管する。CSVが出ない場合や予測対象が0件の場合は、その画面のメッセージとRWLOGを残す。

## 判定と限界

元の5回を1回ずつ学習から除いた検証では、108イベントの次ピーク角RMSEは0.154°だった。新しい測定のうち、開始10秒以降・指令実行・入力前状態が学習範囲内という条件を満たすイベントでRMSEを出す。各回の誤差の偏り、電圧別の誤差、0・10・15・20・25 ms別の誤差も確認する。元の5回に再適用した結果は学習済みデータへの当てはまりであり、独立した確認結果には数えない。

モデルは固定脚、300 mA、上記5種類の入力時間、元の状態範囲で得た暫定式である。係数0.442は観測したホイールの仕事と次ピーク位置エネルギーの残差をまとめた値であり、独立に同定した物理的効率ではない。予測による最良の入力幅が25 msでも目標8°へ届かなければ「この試験範囲では到達不能」と記録し、25 msを超える入力へ外挿しない。
