# 負側30・35・40 msの一括測定

目的は、負側の減速入力を30 msより延ばしたとき、負側の到達角と次の正側の到達角がどう変わるかを同じ測定で確かめることです。これは係数を更新するための測定であり、通常のエネルギー制御則を変更するものではありません。

## 準備と操作

1. 脚の前後移動を固定し、左右には自由に揺れるようにします。過去の固定脚測定と同じ方法を使います。
2. 直立状態で静止させ、必要なら「今の姿勢を直立基準として保存」を押します。バッテリーと固定方法を各回で記録します。
3. 1.0.20を本体に書き込み、実機Web画面の「負側3条件の一括測定を開始」を1回押します。目標8°、指令300 mA、測定30秒は自動で設定されます。
4. 終了後にRWLOGを保存し、ダウンロード完了を確認してから「ログを消去・次の測定へ」を押します。同じ手順で複数回測定します。

負側ZEROクロスには30・35・40 msを3回ごとに重複なく割り当て、順序を試行ごとに変えます。正側の入力は従来の制御です。開始時のキックと姿勢によって、すべての割当条件が実際の出力になるとは限りません。ZEROクロス速度が既存の適用範囲外、直前の正側ピークが7°未満、または電池電圧が7.0〜8.5 Vの範囲外なら、その負側の出力を見送ります。`negative_probe_batch_rate_skipped` はこのモードではこれらの条件による見送りをまとめて示し、個別の理由は同じイベントの速度、直前ピーク、電圧から判断します。

## ログで確認すること

`negative_probe_batch_index` と `negative_probe_batch_planned_width_ms` は割当条件、`pulse_width_ms` とモータ指令は実際の出力です。これらが異なる見送りイベントを、入力した条件の結果として扱わないでください。各負側ZEROクロスに続く負側ピーク、さらにその次の正側ピークを時系列で対応させます。比較ではZEROクロス時点までに分かる速度、前の正側ピーク、ホイール回転速度、電池電圧も保存し、条件間の偏りを確認します。減速中と停止後のホイールの仕事は、既存のRWLOG解析を使って計算します。

40 msは今回の実測応答を調べる条件で、現行の次ピーク予測式の校正範囲（最大25 ms）を超えます。今回のログから入力時間と負側・正側のピークの関係を評価するまでは、40 msを通常の自動制御に組み込みません。
