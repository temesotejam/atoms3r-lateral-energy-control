# 旧到達角予測とエネルギー制御の接続（2026-10-15）

## 比較した式

旧版0.47.31は、ZEROクロスでの左右角速度の絶対値 `v`（°/s）、次に到達する物理側 `s`、モデル上の入力電荷 `Q`（mA·s）から、次ピークの絶対角を直接予測する。

```
A0_s = max(0, a_s + b_s (v - 65))
Apeak_s(Q) = A0_s + g_s Q
```

| 側 | a（°） | b（°/(°/s)） | g（°/(mA·s)） |
|---|---:|---:|---:|
| 正 | 6.730502640 | 0.187441879 | 0.29032 |
| 負 | 7.691200794 | 0.194970900 | 0.25455 |

現行の二次エネルギー式は、同じZEROクロス角速度をrad/sに換算して、次ピークの有効エネルギーを別の係数で予測する。

```
E0_s = max(0, c2_s omega^2 + c0_s)
Epeak_s(Q) = E0_s + alpha_s |omega| Q_As + beta_s Q_As^2
```

この `c2` は慣性モーメントの実測値ではなく、`c0` も損失の独立測定値ではない。`alpha` と `beta` も実機データに合わせた有効応答であり、電気入力から機体へ移った仕事を直接測ってはいない。特に逆入力の応答を無入力時の変化から分けて同定できていない。式の違いは単なる「角度とジュールの単位差」ではなく、自由ピークと入力応答の形、使用したデータが異なることである。

例として `v=65°/s`、目標8°、積分補正なしでは、旧式の自由ピークは正側6.731°・負側7.691°となり、必要なモデル上の `Q` はそれぞれ約4.37・1.21 mA·sとなる。同じ速度で現在の二次式が予測する自由エネルギーは正側約0.000740 J・負側約0.000965 Jで、目標8°の約0.000733 Jを両側とも上回る。したがって二次式はこの状態を不足と判定しない。両式の判断の違いは式を使う前から生じている。

## 新しい接続式

旧式が予測した到達角を、既存の脚形状から計算する位置エネルギー `U(A)` に写す。

```
Efree_s = U(A0_s)
Earrival_s(Q) = U(A0_s + g_s Q)
Etarget = U(Agoal)
Erequest = Etarget + I_s - prediction_bias_s
Qrequired = max(0, (U_inverse(clamp(Erequest, Efree_s, U(Aouter))) - A0_s) / g_s)
```

`Qrequired` を既存の電流立ち上がりモデルから0～100 msの整数入力時間に変換する。左右で別の `a,b,g` を使う。`U` が定義域内で単調である限り、補正がゼロで同じ `Q` を与えた場合、新式の予測角 `U_inverse(Earrival_s(Q))` は旧式の `Apeak_s(Q)` と一致する。エネルギー差 `Earrival_s(Q)-Efree_s` は**実験式をエネルギー座標に写した到達エネルギー増分**であり、モータの仕事や損失を分離して求めた値ではない。

自由ピークのエネルギーが目標より多いときは `Q=0` とし、逆入力しない。旧式の `g_s` は正方向入力用で、負の `Q` に延長するとブレーキの効果を根拠なく仮定するためである。二次式は比較用にWebから選択でき、従来のブレーキ設定を保持する。

積分補正は旧版の `0.1 mA·s/°` を目標付近で局所的にエネルギー座標へ換算し、正側 `0.029032`、負側 `0.025455` 倍のエネルギー誤差を加える。上下限と飽和時の積分停止は現行のままなので、旧版の閉ループ挙動まで厳密に同一にはならない。予測誤差の学習補正はWebから切り替えられ、式の初回比較では「使用しない」を選ぶ。

## 旧版ログで確認できる範囲

0.47.31で取得した独立の固定足3測定について、開始10～30秒の左右ピーク平均は次のとおり。全て旧版の測定であり、現在の本体・原点・電流モデルでの再現を証明するデータではない。

| 目標 | 正側平均 | 負側平均（絶対値） | 左右差 |
|---|---:|---:|---:|
| 8° | 8.215° | 7.980° | 0.235° |
| 10° | 9.711° | 10.768° | 1.057° |
| 12° | 11.970° | 12.682° | 0.712° |

旧式の独立測定ログに記録された角速度と入力Qを与えた一歩先予測では、負側の誤差は旧式で約0.5～0.7°、現在の二次式をそのまま当てると約2.5°の過大予測だった。これは**異なる時期に当てはめた二つの式を旧条件へ適用した比較**であり、現在の二次式が現在の実機条件で常に約2.5°ずれるという意味ではない。

同じログ上の角速度とQを使うと、新しい接続式を `U_inverse` で角度に戻した予測は旧式と数値上同じになる。これは式の代数的な整合性の確認であり、新しい電流入力時間を実行した閉ループ試験ではない。

旧式の `Q` は電流モデルから求めた値で、独立した電流積分の計測値ではない。旧式は測定開始時の角度を原点としたが、現行版は保存済みの直立姿勢を原点にする。MEKFのイベント判定、入力タイミング、実機状態も変わりうる。代数的な一致と、実機の左右ピークが再びそろうことは区別して検証する。

## 実機での最初の確認

保存した直立基準と足固定条件をそろえ、8°・300 mA・学習補正なしで新モードを測る。RWLOGの `energy_model`、正負ピーク、`free_next_peak_amplitude_deg`、`predicted_next_peak_amplitude_deg`、`q_command_mA_s`、入力時間、ZEROクロス時刻、次ピーク時刻、ホイール速度、実電流を照合する。過剰側で逆入力が出ないこと、`energy_model_extrapolated` と処理期限超過も確認する。同じ条件の二次式測定と比較し、10°・12°へ広げる。旧式の原点変更や電流応答の違いが残るので、新たな実機記録を見てから係数の再同定が必要か判断する。
