# 1.0.33：MEKF絶対角0°を基準とする仕事制御

通常の「仕事に基づく制御で30秒測定を開始」は、MEKFのposterior pitchをそのまま左右角に使う。保存した直立姿勢や測定開始姿勢を差し引かない。目標は＋8°・−8°で、ゼロクロス・ピーク・目標位置エネルギー・振幅に基づく入力制限を同じ座標にそろえる。比較用の旧実験プリセットは従来の保存姿勢基準を維持する。

位置エネルギーは `U(theta)=U0(theta)+m*g*dx*sin(theta)` とし、符号付きの目標角から左右別に計算する。入力中と入力後の仕事を含む到達エネルギー予測を目標と比較して電流と時間を選ぶ。電流時間積分をエネルギーそのものとは扱わない。

重心の左右偏りによる奇関数項は残す。ただし、自動推定するdxは左右のモデル誤差や損失も含む等価値であり、物理的な重心位置を一意に測定した値ではない。旧原点で得た補正初期値と共通バイアスは引き継がず、各Runでゼロから始める。新たに明示指定した絶対角基準の手動値だけは初期値に使える。保存形式version 2で旧形式version 1と区別し、旧値が偶然0°基準でも再利用しない。

絶対角基準へ変えると入力タイミングとモデルに渡す状態も変わる。既存の到達エネルギー回帰式は初期モデルとして再利用し、新しい閉ループ性能は実機で確認する。係数を今回の基準で再同定したという意味ではない。原点変更だけで左右8°への収束を保証しない。

RWLOGには `control_angle_origin_abs_deg=0` と `work_absolute_reference_enabled=true` を追加する。既存の `upright_reference_abs_pitch_deg` は保存姿勢の診断値として残すため、新ログのピークにその値を再加算してはいけない。`pitch_mekf_measurement_relative_deg` は仕事制御では絶対角と同じ値になる。旧ファイルの意味は変更しない。

検証：原点の保存値によらない±8°、旧補正値の拒否、左右別エネルギーから角度への逆算、既存の動作中適応、Web開始条件、RWLOG出力と本体ビルドを確認する。実機での到達精度は次の測定で評価する。
