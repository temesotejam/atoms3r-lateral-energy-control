# 保存した直立基準を使う左右揺動制御（1.0.7）

## 操作

1. 本体を起動し、IMUの準備が終わるまで待つ。
2. 足を試験条件どおりに固定し、胴体を基準にする姿勢で静止させる。
3. 本体のWeb画面で「今の姿勢を直立基準として保存」を押す。
4. 約2秒間その姿勢を保ち、「本体に保存しました」と表示されることを確認する。
5. 測定を開始する。次の測定でも同じ基準を使う。意図して変更するときだけ再取得する。

本体のNVSに単一のバージョン付きレコードで保存し、読み返して確認する。ログ消去・STOP・通常の再起動では消さない。フラッシュ全消去では消える。初回や保存レコードが無効な場合は測定を開始できない。

取得はREADY_TO_MEASURE / FINISHED / ESTOPの停止中のみ。取得中・開始準備中・運転中・ログ生成中は変更できない。完了したログが残っていても基準を更新できるが、そのログに記録された基準は変わらない。

## 原点

制御角 = MEKFの現在のpitch − 保存した直立基準のpitch。

測定開始時に新しい制御原点を取得しない。開始前の同期中に行うMEKFの姿勢初期化は残すが、保存した直立基準は変更しない。ピーク角、エネルギー換算、ZEROクロス、左右角の上限判定が同じ原点を使う。

開始姿勢の確認にも保存時の正規化加速度X成分を使う。昔の直立姿勢との差を、新しく保存した基準の判定に使わない。足カメラのゼロ点と前後姿勢比較は独立した記録機能である。

機構の直立姿勢自体は操作者が決める。任意の姿勢を保存すると、その姿勢が0°になる。2秒平均は測定ノイズを減らす処理であり、機械的に正しく直立していることを自動判定する処理ではない。

## 取得条件

新しいMEKF/IMUサンプルだけを約2秒間平均する。加速度の大きさ1g±0.03g、ジャイロ全軸ノルム1.5°/s以下、取得中のpitch最大−最小0.5°以下、IMUの直立側の半球を条件とする。姿勢推定の鮮度やセンサ状態も確認する。機体が動いた場合は取得を失敗として、以前の基準を使い続ける。これらは静止取得の暫定条件であり、直立精度を保証する値ではない。

## 記録と互換性

RWLOG v54のバイナリ列は変更しない。1.0.7の自動制御では、既存のpitch_mekf_measurement_relative_degとpitch_mekf_detector_relative_deg列が保存した直立基準からの角度になる。旧版の「測定開始基準」とは意味が違うため、ファームウェア版とangle_reference_policyを確認する。

メタデータにupright_reference_valid / revision / abs_pitch_deg / normalized_ax / samples / spread_degを記録する。測定開始時の角度はmeasurement_start_abs_pitch_degとmeasurement_start_upright_relative_degへ、原点と別に記録する。基準レコードは開始時にログへコピーするため、測定後の基準更新でも過去ログの解釈は変わらない。

既存のエネルギー予測係数・電流モデル・入力上限は今回変更していない。角度基準が変わるので、以前のデータとの比較には原点の違いを考慮し、無入力予測と制御後ピークの誤差を再確認する。
