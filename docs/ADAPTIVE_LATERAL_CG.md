# 動作中の等価重心ずれの適応（1.0.31）

1.0.33の通常仕事制御は[絶対角基準](ABSOLUTE_ENERGY_REFERENCE.md)へ移行し、以下の旧原点で得た初期値は使わず、補正ゼロから始める。

## このログから読み取れること

対象は `energy_control_autonomous_run_1_124463989.rwlog`。10～30秒の平均ピークは正側7.958°、負側9.338°だが、左右の入力と損失は同一ではない。負側は21回とも許可上限の入力を使っている。したがって、ピーク中点や振幅差だけから物理的な重心ずれは特定できない。直立基準の誤差、左右の損失差、仕事回帰モデルの左右の誤差も交絡する。

制御に利用するため、これらを含む左右の偏りを「等価重心ずれ」としてモデル化する。これは重心位置の直接測定ではない。

## エネルギーの一貫性

`U(theta,x) = U0(theta) + m*g*x*sin(theta)` を使う。角度の原点や±8°の目標は固定し、左右それぞれの角度に必要なエネルギーを変える。

仕事モデルの補正前の到達エネルギーをEraw、共通の予測誤差をbとすると、ピークで

`U0(theta) + m*g*x*sin(theta) = Eraw + b`

が成り立つようにxとbを求める。mJ・mm単位では、

`r = U0(theta)[mJ] - Eraw[mJ] = b - k*x`

`k = m*g*sin(theta)`（mJ/mm）

となる。左右の観測がないとbとxを分離できないため、一方だけでは更新しない。左右別の独立したバイアスを同時に学習すると重心項と重複するため、仕事モデルの正側branch6と負側branch4は、この共通bとxに統一する。正側の起動・適用範囲外のbranch5は従来の一時的な残差補正を残し、xの更新時にその履歴を消去する。

既存の電圧・回転数・入力後の仕事を含む回帰式は維持する。候補ごとのEraw+bを計算し、左右別のU(±8°,x)に最も近い電流と通電時間を選ぶ。Qや電流積分をエネルギーと同一視しない。

## 初期値と更新

上記ログの有効なbranch4/6の41件（入力判定時刻10～30秒）で回帰すると、等価xは−0.20588 mm、共通bは+0.02262 mJ、回帰のエネルギーRMSEは0.06732 mJとなる。この符号は既存モデルに対する符号で、機体の重心が実際にどちらへ移動したかを証明しない。左右それぞれに独立した未知の損失を認めれば、同じ観測を別の重心位置でも説明できる。

未設定時はこの値を初期値にする。±8°の初期目標は正側約0.67731 mJ、負側約0.78954 mJ。従来の手動値は任意の初期値として利用できるが、入力不要で開始できる。直立基準は引き続き必要であり、動作中に原点を動かさない。

更新条件と制限は以下のとおり。

- 開始5秒以降、6～13°の有効な実測ピーク、対応する入力前の新鮮なホイール情報、照合できた仕事モデルの入力が対象。
- 正側branch6と負側branch4の隣接する観測を対にする。間隔が1.4秒を超える対、非有限値、0.5 mJを超える残差を棄却する。
- 最初の3対がそろってから、直近最大8対の回帰を更新する。
- 回帰値へ20%ずつ近づけ、1対でxは最大0.025 mm、bは最大0.01 mJしか変えない。
- xの範囲は±2 mm、bの範囲は±0.25 mJ。毎回の測定開始で初期化し、動作中はフラッシュへ書き込まない。
- 入力決定時のxを保存し、その入力後のピークの目標・実測エネルギーは同じxで評価する。更新したxは次の入力から使う。
- 各ZEROクロスとピークに使用したxを記録し、実行全体の初期値・最終値・観測対数・更新回数・棄却回数もRWLOGへ保存する。

負側の25～70 msの段階的な上限と反対側の振幅保護は維持する。推定ができても、入力上限や反対側の保護により目標へ届かない場合がある。この適応だけで8°への収束を保証しない。

## 検証と使用手順

`tools/fit_adaptive_lateral_cg.py` が初期値を再現する。ログのハッシュと53件の有効観測の抽出条件は同名fixtureに保存した。

`tools/test_adaptive_lateral_cg.cpp` では、既知の重心項と共通誤差を持つ合成データでの回復、一方だけでは学習しないこと、更新速度、異常値・古い対の棄却を確認する。実ログの記録済み入力を時刻順に再生すると、x=0・b=0から25対で23回更新し、最終xは約−0.20459 mmとなる。これは次の実測ピークを見てからその前の入力を決める処理ではない。ただし、適応で選び直した入力の効果を実測したものでもない。初期値の回帰と同じログを使っているので、独立した実機検証ではない。

最新版を書き込み、従来の直立基準を確認して「仕事に基づく制御で30秒測定を開始」を押す。重心ずれの保存ボタンを押す必要はない。画面の「自動補正」と更新回数を確認し、RWLOGで振幅誤差、入力飽和、反対側保護、適応値の推移を評価する。
