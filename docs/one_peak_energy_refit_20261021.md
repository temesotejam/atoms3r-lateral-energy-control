# 一つ先の負側ピーク予測式：14回の測定で再学習

## データと適用範囲

固定脚・負側5条件の一括測定、ファームウェア1.0.16、保存された直立基準の絶対角1.932539°、指令電流300 mAの14回を使用した。開始10秒以降、入力時間が割当どおり実行され、次の負側ピークと入力中・入力後のホイール仕事が対応付いた304イベントを学習対象とした。候補時間は0、10、15、20、25 ms。

入力前の機体角速度、ホイール回転数、直前ピーク、電池電圧、割当入力時間だけを予測時に使用する。次のピークと測定された仕事は、学習時の目的変数であり、予測時の入力ではない。学習範囲は角速度57.2522～76.2778°/s、ホイール回転数4.28～550.04 rpm、直前ピーク5.0288～8.52741°、電池電圧7.22～8.00 V。範囲内でも未測定の組合せまで精度が保証されるわけではない。

以前の5回・108件は保存された直立基準が1.772013°で異なる。19回を単純に一つの式へ混ぜた場合、1回ずつ除く検証で、新しい14回のRMSEは0.284°だったが、古い5回は0.266°となり、以前の5回のみの式の0.154°より悪化した。そのため、今回の式は新しい直立基準の14回で学習し、Web上の観測専用予測に使用する。古い基準のログは学習条件外と表示する。

## 式

機体のピーク位置エネルギーを `U(θ)` として、

```text
ΔW(T,x)     = W_on(T,x) + W_after(T,x) - W_after(0,x)
U_pred      = E_0(x,V) + η ΔW(T,x)
θ_pred      = U^(-1)(U_pred)
η           = 0.42290164040184
```

`x` は入力前の機体角速度、ホイール回転数、直前ピーク。`E_0` は入力0 msで次のピークに到達するエネルギーを近似する経験式であり、現在の機体エネルギーと損失を独立に測った値ではない。`W_on` と `W_after` は暫定のホイール慣性2.8×10⁻⁵ kg m²から計算した観測仕事を教師として推定する。`η` は残るずれを吸収する回帰係数で、機械効率を示す測定値ではない。

係数は `site/one-peak-energy.js` に記録した。今回の電圧係数は約+0.00474 mJ/Vとなり、古い5回の約+0.099 mJ/Vから変わった。電圧と測定順・入力前状態が交絡するため、電圧の影響が消えたと解釈しない。

## 評価

| 評価 | 対象 | 次ピーク角RMSE | 平均誤差（予測－実測） |
| --- | ---: | ---: | ---: |
| 古い式を固定して新しい14回を予測 | 304件 | 0.489° | +0.390° |
| 新しい式を14回のうち1回ずつ除いて再学習・予測 | 304件 | 0.289° | +0.004° |
| 新しい式を1～12回で学習し13・14回を予測 | 44件 | 0.290° | +0.026° |
| 新しい式を全14回で学習し同じデータを予測 | 304件 | 0.266° | +0.003° |

最後の行は学習誤差であり、未知の試行に対する精度ではない。13・14回は1～12回の学習から除いたが、この再学習方針の検討には結果を参照しているため、完全に独立した将来試験とは呼ばない。次の新しい試行で式を固定したまま検証する必要がある。各回を除いた検証ではrun 5とrun 6のRMSEがそれぞれ0.422°、0.404°で、条件による残差は残る。

この式はWeb上のログ照合専用で、実機の電流・入力時間の決定には使われない。8°目標が0～25 msで到達可能になったかも、別途確認が必要である。範囲外の入力時間や脚を動かした歩行には外挿しない。
