# 左右・ホイール回転数帯を用いた予測誤差補正

## 導入の根拠と限界

固定脚、目標8°、指令300 mA、負側ブレーキ上限50・20・0 msの3ログを照合した。開始5秒後からの到達角平均は、正側が順に6.20・8.09・7.72°、負側が8.10・10.12・10.34°だった。50 msと20 msでは正負の差がどちらも約2°で、ブレーキ上限だけでは左右差が消えない。到達角と従来のエネルギー予測の差も、側と条件によって異なる。

入力前のホイール回転数は50 ms条件で正側約359 rpm・負側約519 rpm、20 ms条件で約29 rpm・約167 rpmだった。ただし設定値、回転数、ZEROクロス角速度、入力時間が同時に変わるため、この3ログから「回転数が何 rpm 増えるとピーク角が何度変わる」という固定係数は分離できない。実際、予測誤差と回転数の傾きは試行内でも一致しない。回転数を使う範囲は、その試行中に観測された予測誤差を似た状態へ適用するために限定した。

## 制御に使う値

ZEROクロスでの従来モデルを `E_model = E_free(side, ω) + W(side, ω, Q)` とする。ピーク検出後、対応するZEROクロスについて `r = E_measured_peak − E_model` を求める。正の `r` は実測ピークが予測より大きかったことを示す。次回の同じ条件では、逆算する入力エネルギーを `E_target − E_free + I_side − r_hat` とする。`r_hat` は以下の条件を満たした履歴から得た値である。

- 物理的な正側・負側を分ける。
- 機体の進行方向に対する加速入力・逆入力を分ける。無入力の誤差は入力補正へ混ぜない。
- 入力前ホイール回転数の符号を保ち、`<-100`、`[-100,100)`、`[100,300)`、`>=300 rpm` に分ける。
- 測定開始5秒後以降、同じ区分で同符号かつ絶対値0.000010 Jを超える誤差が4回続いた場合だけ使う。更新率は0.25とし、誤差の符号が変わったら連続回数を数え直す。
- 絶対値0.000200 Jを超える観測は学習しない。採用する補正は最大0.000070 Jで、さらに未補正の入力要求の半分を超えない。
- 回転数データが無効、50 msより古い、または絶対値1000 rpm超の場合は補正0とする。補正後に入力方向が変わる場合も未補正の計算に戻る。

補正は試行ごとに初期化する。MEKF、重力位置エネルギー式、左右別の既存係数、指令電流、パルス幅上限、16°停止条件は維持する。RWLOGのZEROクロスには回転数帯、連続観測回数、採用した補正値、補正込みの予測ピークを追加し、ピークには学習に使う誤差を記録する。

## 既存ログでの確認と次の実機測定

古い3ログの入力を変えず、過去のピークだけから次の予測誤差を補正する時系列照合を行った。20 ms条件では、5秒以降のエネルギー予測誤差の二乗平均平方根が正側で0.0000214→0.0000158 J、負側で0.0000841→0.0000597 Jだった。50 ms条件の負側でも0.0000462→0.0000380 Jとなった。0 ms条件では連続観測の条件を満たさず、入力に反映されない。50 ms条件の正側は0.0000316→0.0000331 Jでわずかに悪化したため、この照合は補正の効果を保証しない。

この照合は**新しい入力での機体の応答を再現した試験ではない**。実機では負側ブレーキ上限20 msをまず基準にして同条件を複数回測り、補正が発動した周期と発動しない周期の左右ピーク角、回転数、指令と実電流、上限到達を比較する。20 msでは負側ブレーキが上限に達していたため、予測補正だけで負側の約2°の超過が解消するとは見込まない。
