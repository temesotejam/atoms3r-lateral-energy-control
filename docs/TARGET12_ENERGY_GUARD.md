# 1.0.38：目標12°の予測補正と過大入力の抑制

## 対象と変更

固定脚・絶対角0°基準の仕事制御を対象とする。目標12°では、確定した6〜15°のピークを左右別の到達エネルギー補正に使う。目標8°・10°の6〜13°条件は保持する。残差の許容上限は既存の `0.5 mJ × max(1,U(target)/U(8°))` とする。16°の実角度による停止条件は変更しない。

12°で13°を超えた実測値が除外され、補正が2件に達しない状態で過小予測が続く問題に対応する。負側の補助入力上限の調整も同じ15°まで観測し、13°超の過大応答で時間上限を縮められるようにする。

## 正側のエネルギー補正

各予測モデルの残差を従来どおり別々に保存する。角度や入力時間の差ではなく、測定ピークの位置エネルギーと生の到達エネルギー予測との差を使う。

```
r_i = 1000 U0(measured_peak_i) - E_raw_i              [mJ]
k_i = m g sin(measured_peak_i)                      [mJ/mm]
b_i(x) = r_i + k_i x
b_mean(x) = clamp(mean(last 3 b_i(x)), ±residual_limit)
```

目標12°の正側で、実際の到達エネルギーが前回の補正済み予測を `1000[U0(12.5°)-U0(12°)]` より大きく上回った場合、次の同一モデルの補正には `max(b_mean, clamp(b_latest))` を使う。通常の平均がまだ使えない1件目から、直近の過小予測への対応を許可する。これは試験用の保守的な予測値選択であり、統計的な信頼上限ではない。

平均と直近値を足し合わせない。重心の推定値が更新された場合も現在のxで再表現する。直近値が平均に既に含まれている場合の二重加算を避ける。

補正後の予測到達エネルギーを左右別の目標位置エネルギーと比較し、候補の電流・時間を選ぶ。入力中と入力後の仕事を含む元の予測式、電圧による電流応答、ホイール回転状態を引き続き使う。電流時間積分をエネルギーと同一視しない。

## 補正範囲外の応答

12°の正側で、確定ピークが15°を超えるか、残差が目標に対応する許容上限を超えた場合、その予測モデルを使う次の判断では無入力だけを候補にする。範囲内の観測を受け付けると解除する。元の学習範囲外の値をそのまま回帰に追加したり、出力上限や停止角度を増やしたりはしない。

正側の混合モデルでは、使われる成分にこの制限がある場合に加振を見送る。混合モデルの残差を単独の仕事モデルの残差へ混ぜない既存条件も保持する。

重心推定は左右が揃った従来の条件で動作する。左右別の到達エネルギー補正の範囲を広げても、大きな予測誤差をそのまま実際の重心移動と解釈しない。

## 検証と限界

ホストテストで、13〜15°の観測受付、1件目の過小予測への対応、二重加算しない補正、重心推定更新時の再表現、補正範囲外での無入力化と復帰、負側補助入力の過大応答、8°・10°の従来範囲を確認する。

実測ログの再計算では、各ZEROクロスより前に確認されたピークだけを使う。記録時の入力に対する次ピーク予測の評価と、新しい入力候補の選択を区別する。元の軌道を固定した再計算は、新しい入力を与えた実機の収束や停止回避を証明しない。12°での閉ループ動作は書き込み後の実測で確認する。
