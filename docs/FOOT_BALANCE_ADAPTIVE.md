# 左右の足マーカーを使った歩行中の目標調整

対象は仕事制御で目標8°を選んだ場合。開始時は左右とも8°。
右傾きのピークでは左足、左傾きのピークでは右足の直立基準からの
校正済みマーカー変化を使う。ピークの100 ms以内に撮影された、同じ
計測の有効な画像だけを使う。検出不能や時刻不一致では観測を加えない。
校正範囲外でも有効な観測は従来どおり保存し、補間・外挿値を使う。

左右それぞれ3回の平均が揃い、どの観測も5秒以内の場合に比較する。
差が0.3度換算を超えると、小さい足が動く方向の目標を0.1°上げ、
反対側の追加分を0.1°下げる。最大追加は各1°、更新間隔は2秒以上。
観測が欠けたときは目標を保持し、次の計測では8°に戻す。
閾値は暫定値であり左右足の画像座標から換算した指標で、直接計測した対地角ではない。

選択した基準目標 `target_peak_deg` は8°のままなので、既存モデルの
離散的なモデル選択は保つ。`foot_balance_target_deg` は調整後の値で、
実際の `target_energy_j` はこの値を位置エネルギーに変換したもの。
ピークの目標エネルギーも、そのピークを予測したときの値を保持する。
`foot_balance_left_mean` と `foot_balance_right_mean` は各3回の平均、
`foot_balance_left_deg` と `foot_balance_right_deg` はZEROクロス時の最新の有効値。
実際のカメラ画像時刻と各足の値は既存 `foot_frames` に記録される。

既存の入力電流・時間上限、モデルの範囲判定と停止条件は維持する。
したがって目標が上がっても入力が見送られたり飽和したりする場合がある。
ジャイロ効果、RW回転数の平均、直進の補償機能は追加していない。
実機の足角度の精度、左右差の減少、直進と目標角度への到達は未検証。
