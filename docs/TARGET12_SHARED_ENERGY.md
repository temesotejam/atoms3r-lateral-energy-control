# 1.0.39：目標12°の負側に共通の到達エネルギー補正

## 修正の対象

固定脚・絶対角0°基準の12°試験で、負側の補助入力を長くするほど予測上のエネルギーが小さくなる区間が発生した。原因の一つは、無入力用と補助入力用の残差をq依存の重みで混合し、その補正差が仕事の増分を打ち消すことである。

今回、12°ではこの混合を除く。無入力・ブレーキ・補助入力のすべてに同じ負側の到達エネルギー補正を使う。8°・10°の入力選択、および12°正側の過大入力抑制は従来のまま。

## エネルギーの計算

状態sはZEROクロスの角速度、ホイール回転状態、電圧、直前ピーク。B_rawは従来の負側無入力モデル。qは電流応答モデルから計算した電流時間積分量[mA s]、ωはZEROクロス時の機体角速度の大きさ[rad/s]。以下はmJ単位。

```
E_pred(coast)  = B_raw(s) + b_negative(x)
E_pred(brake)  = B_raw(s) + b_negative(x) + ΔE_brake(s, t)
E_pred(assist) = B_raw(s) + b_negative(x) + κ q ω
κ = 0.22502117220 × 0.06189960458
E_target = 1000 U(-12°, current_CG)
```

ΔE_brakeは従来の入力中・入力後の仕事を含むモデルの、無入力からの到達エネルギー変化。補助入力のκは正側の仕事モデルから移した暫定値を維持する。今回のログから負側の物理的なゲインや効率を同定したとは扱わない。実際の長い入力の効果や入力後の減速の影響は、実測で確認する。

予測モデル上はq=0で無入力と一致し、補助入力の仕事増分がqとともに増える。補正値そのものはqで変えない。これはモデルの人工的な極大を除く修正であり、実機のすべての状態で仕事が単調に増えることを実証したという意味ではない。

## 共通の補正の更新

鮮度と対応付けの条件を満たした負側ピークを、入力の有無にかかわらず同じ残差バッファへ入れる。

```
r_i = 1000 U0(actual_peak_i) - E_raw(selected_action_i)
b_negative(x) = clamp(mean(last3 [r_i + signed_CG_coefficient_i × x]))
```

入力した場合は、その入力に対する生の予測を引く。実測値を無入力時の結果と取り違えない。補正には従来の角度範囲・残差上限を適用し、2件から平均を使う。

この補正は損失や入力効果の誤差も含む有効な到達エネルギー残差で、真の無入力エネルギーを一意に特定した値ではない。入力ゲインと無入力損失を、この残差だけから同時に同定しない。重心推定へは従来どおり補助入力の結果を混ぜず、現在の重心推定で残差を再表現する。

## 入力候補と上限

全候補の予測到達エネルギーを目標の位置エネルギーと比較し、誤差が最小の電流・時間を選ぶ。届く候補があれば短い入力を選び、届かない場合は到達不能のフラグを残す。

12°の補助入力上限は25 msから始める。上限まで補助しても目標−0.3°未満だった応答を2件確認すると5 ms拡張する。その2件の間に無入力やブレーキの周期があっても、上限不足の実測記録を消さない。別の補助入力で上限不足が確認できなかった場合は件数をリセットする。過大な補助応答では従来どおり上限を5 ms縮小する。

補助入力300 mA・最大100 ms・25 mA s、ブレーキ最大70 ms、正側の候補と抑制、電圧・回転状態・鮮度の外側適用範囲、16°停止条件は維持する。上限が広がっただけで常に最大入力を出す制御ではない。

## 検証と限界

合成テストで、同じq=0の到達エネルギー、qに依存しない補正、仕事の入力中・入力後への分解、モデル上の増分、上限候補と内側候補の選択、過剰時のブレーキ、上限不足の記録保持と過大応答時の縮小、入力制限を確認する。

実測ログの再計算は、そのZEROクロスより前に確定したピークだけを使う。元の入力に対する予測の確認と、新しい入力を選ぶ場合の比較を分ける。元の軌道を固定した再計算から、新しい入力を与えた際の軌道・収束・実際の仕事を断定しない。公開後の12°測定で確認する。
