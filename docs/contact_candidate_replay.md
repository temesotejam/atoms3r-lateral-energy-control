# 足・姿勢の候補時刻リプレイ（研究用）

リポジトリルートから実行する。

```powershell
python tools/replay_contact_candidates.py work/run305 work/run160 work/run329 work/run337 work/run404
python tools/replay_contact_candidates.py --calibrated-run305 work/run305
python test/test_contact_candidates.py
```

候補作成は撮影記録の `measurement_time_us` に記録の `delivered_us - frame_us + processing_us` を加えた時刻と、それ以前の最新 IMU のみを使用する。IMU 年齢 25 ms 以下、ZERO の線形予測まで 80〜300 ms、内向き運動、足測定の有効性を要求する。幾何モデルの等高さ角が、全仮説で同方向、現角度から未通過、ZERO から 0.25°超、幅 1.5°以下なら、ZERO に最も近い等高さ角を候補とする。ZERO 事象は候補生成後に読み込み、500 ms 以内の次の ZERO との対応付けと実測しきい値到達の採点にのみ利用する。これは後処理による評価であり、一歩に一回の排他、最新フレームへの更新、実機での ZERO フォールバックは実装していない。

通常モードは体の前後傾、左右各足角について独立に符号を反転し 8 通り、股関節高さ 55.33、82.83、120 mm を比較する。仮説全体で符号が一致した場合でも、座標・初期姿勢・接地などモデル化されていない不確実性は残る。

`--calibrated-run305` は run305 専用で、起動時相対角に左 +1.246°、右 +1.784°を加えて校正表の基準を戻す。足角正方向は前、モデルの X 回転の正方向に対応すると仮定し、体の前後傾の符号 2 通りと上記高さ 3 通りを比較する。起動時の差は機械的中心を確認したものではなく、足の絶対角を保証しない。左右符号独立の曖昧さを外しており通常モードとの比較は条件付きである。

run305 の通常モードは適格 40 フレーム中候補 1 件、記録された有効 ZERO 34 件中 1 件に対応した。校正表基準に戻す条件付きモードでは 40 フレーム中候補 6 件、ZERO 34 件中 6 件に対応し、6 件の IMU しきい値到達は ZERO の 38〜97 ms 前だった。一方、線形予測の候補到達時刻は 1 件で実際の ZERO より 3.7 ms 後となった。結果は実測対象への一般化や実機制御の検証を意味しない。

両足の等高さは接地・荷重移動を表す測定ではない。カメラ時刻が露光時刻であること、制御側への実際の公開・読取時刻、画像処理後の遅延は確認されておらず、算出した利用時刻は下限である。時間計測と座標・機械基準・接地の確認なしに実機へ適用しない。線形予測にも誤差があり、事後の早期到達だけでは ZERO 期限や安全性を保証できない。
