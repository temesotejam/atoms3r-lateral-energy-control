# 1.0.37：負側の不足エネルギーを補う試験用制御

対象は脚を前後に固定した目標10°・12°の試験。8°では補助入力を有効にしない。絶対角0°基準と左右別の目標位置エネルギー、動作中の補正を保持する。

## エネルギー計算

従来の負側モデルは無入力とブレーキのみを比較していた。補正後の無入力到達エネルギーが目標を下回っている場合、どれだけ目標未達でも無入力が選ばれる。この片方向の入力集合を拡張する。

補助入力の到達エネルギーは、負側の無入力到達エネルギーに、正側の既存モデルから移した仕事増分を加えて計算する。qは既存の電流応答モデルから予測する電流時間積分量[mA s]、ωはZEROクロス時の機体角速度の大きさ[rad/s]。

```
ΔW = 0.06189960458 q ω                           [mJ]
E_pred_assist = E_raw_negative_coast + 0.22502117220 ΔW + b_assist
E_target = 1000 U(signed_target, current_CG)       [mJ]
```

上式のb_assistは、無入力の補正から補助入力専用の補正へ、q=0〜5 mA sの滑らかな重みで移す。q=0では無入力予測と完全に一致させ、小さい補助入力を選んだだけで予測エネルギーが不連続に変わらないようにする。

ΔWは入力中と入力後の仕事増分を含む経験的な予測。電流時間積分をエネルギーと同一視しない。負側の無入力モデルを使い、左右の基礎エネルギーや損失を対称とは仮定しない。ただし追加仕事の係数を正側から移す仮定は未検証で、負側の実測から同定した係数ではない。すべてbranch 9、cross-conditionとして記録する。

入力中の仕事増分は正側の係数0.09858037463 q ωを初期値とし、入力後はΔWとの差とする。これらも負側の実測精度を保証するものではない。実測の仕事は従来どおり位置・角速度ログから別途計算する。

ブレーキ・無入力・補助入力の予測到達エネルギーを目標と比較し、誤差が最小となる入力を選ぶ。補助入力は身体運動と同方向、ブレーキは反対方向の反作用を起こす符号で指令する。

## 入力の条件

- 目標10°・12°で、実測の負側ピークが目標−0.3°未満に2回連続でなった後、補助入力を許可する。許可後も、現在の補正済み無入力予測が目標より0.03 mJ以上不足する場合だけ候補に加える。目標に達しただけで許可を解除しない。
- 補助入力は300 mA。時間上限は25 msから始める。上限まで補助しても目標−0.3°未満が2回続いたら5 ms拡張し、最大100 ms、電流時間積分量は25 mA s以内。過大になった場合は上限を5 ms縮小する。
- ブレーキの最大70 msと正側振幅による抑制を維持する。正側が小さい場合の抑制はブレーキに適用する。補助入力を一緒に禁止しない。
- 鮮度・電圧・回転数・角速度・直前ピークの従来の外側適用範囲を維持する。補助入力は7000 mV以上、境界では時間上限もモデルの重みで減らす。
- 補助入力とブレーキ／無入力の残差を別々に学習する。補助入力で得た残差は重心ずれやブレーキ上限の学習へ混ぜない。各測定で補助入力の許可・上限・補正を初期化する。

## 目標角に合わせた予測補正

左右別残差の棄却・補正上限を `0.5 mJ × max(1,U(target)/U(8°))` とする。8°は従来の0.5 mJ。大きい目標でも同じ絶対上限によって更新が止まる問題を避け、許容する誤差を目標位置エネルギーに対してそろえる。6〜13°の観測角条件、直近3件、2件から適用、現在の重心推定での再表現は維持する。

## 検証範囲

ホストテストで不足時の入力選択、過剰時のブレーキ、出力符号、仕事の入力中・入力後への分解、段階的上限、適用範囲と鮮度による棄却、8°で補助しないことを確認する。過去ログの状態を固定した因果的な判断の再計算は、入力選択の確認であり、新しい入力を与えた場合の将来の軌道や収束を実証するものではない。負側補助入力のゲインと閉ループ精度は実機で確認する。
